# Augmented Reality (AR) Fastfood Menu Interactive App

Aplikasi Menu Makanan Cepat Saji berbasis Augmented Reality (AR) interaktif yang dibangun menggunakan **Unity Engine** dan **Vuforia SDK**. Proyek ini dirancang untuk menampilkan visualisasi produk makanan 3D secara real-time ketika kamera perangkat diarahkan ke target penanda (Image Target/Marker).

---

## 🚀 Fitur Utama
* **3D Object Visualization:** Menampilkan model makanan 3D yang detail dan presisi di atas marker.
* **Interactive Gestures:** Mendukung interaksi manipulasi objek langsung di layar (Geser posisi/*Translate*, Ubah ukuran/*Scale*, dan Putar objek/*Rotate*).
* **Audio & Text Description:** Menyajikan deskripsi edukatif mengenai menu makanan beserta narasi audio otomatis saat objek muncul di kamera.
* **User Guide Page:** Halaman panduan pemakaian yang intuitif pada menu awal untuk memudahkan pengguna baru.

---

## 🛠️ Spesifikasi Teknologi
* **Engine:** Unity (Saran: Buka menggunakan versi Unity LTS yang sama saat proyek ini dibuat)
* **AR SDK:** Vuforia Engine SDK
* **Target Platform:** Android / iOS Mobile Devices
* **Language:** C# (C-Sharp)
